## 三、实施方案（三阶段）

### 阶段一 · 部署与快速见效（本周）

- [ ] **P1-1 部署今日改动**：重启后端，加载 2026-09-30~10-01 的全部修改——视频模式收敛
      （只保留整集）、action 接线（KEY ACTION BEAT）、script_generator schema 补齐、
      cancellation 上下文污染修复、run-once 解除持久化暂停、增强/复审重开（新提供商）。
      验收：`/api/agent/tools` 正常、run-once 第 1 集能走完视频提交且不再被中止信号打断。
- [ ] **P1-2 场景九宫格机位预览 MVP**（G2，不装第三方节点）：把 `SCENE_VIEW_ANGLE_ZH`
      的 9 条机位文案拼成一张 3x3 多角度提示词，走现有 Qwen-Image-Edit 链路一次生成
      「9 机位预览图」；质检模型给 9 格打分选最佳；选中的机位走现有
      `SCENE_ANGLE_TO_VIEW` 精修出正式图。改动点：`nine_grid_storyboard.py` 或新增
      `scene_grid.py` + `app.py` 一个端点 + 前端场景卡片加「九宫格预览」按钮。
- [ ] **P1-3 剧本重生成验证**：用补齐后的 script_generator schema + 新提供商重生成
      测试项目第 1 集剧本，确认 action/shot_type/beat 等新字段被真实产出，并复核
      分镜图提示词里 KEY ACTION BEAT 行的出现。

### 阶段二 · 一致性与候选构图（1~2 周）

- [ ] **P2-1 分镜九宫格候选构图**（G1）：按 BigBanana 机制，分镜生成前先出一张
      「9 候选构图」网格（同镜头、9 种机位/构图变体提示词，一次生成），QC 模型打分
      选最佳 → 裁切该格作为分镜图（或作为首帧走精修）。与现有 best-of-N 并存成
      「九宫格模式」，由质检配置开关（借鉴 `best_of` 的做法加 `grid_candidates`）。
      验收：同镜头九宫格模式的 QC 通过率/耗时优于 best-of-N。
- [ ] **P2-2 RefMod PoC**（G3）：验证 ComfyUI-MiniMaxH3Mod / Fizgig RefMod 的节点
      能否过本项目 `UI→API` 转换与 `validate_api_prompt` 自检（社区节点多为 UI 模式，
      这是唯一集成风险）。可行 → 角色卡新增「参考包」生成与加载；不可行 → 研究
      .safetensors 格式直接在 `comfyui_client` 注入，或退回 G3 备选（多图槽位现状）。
- [ ] **P2-3 逐段主体一致性门禁**（G4）：`qc_client` 视频层新增「主体一致性」检查
      （当前段与该段参考图/上一段的角色一致性），与现有跨镜一致性复检合并口径，
      命中即自动重生成（沿用现有重试上限）。参考 Story Claw 的门禁节点行为。

## 四、独立问题跟踪（本轮调研顺带发现，不属于对标）

- [ ] **QwenTTS 批量任务在 ComfyUI 队列挂起 30+ 分钟**（`配音超时（>1800s）`）：
      TTS 卡队列会把排在后面的 H3 视频任务一起堵住。排查方向：Qwen3-TTS 工作流
      是否偶发不返回、ComfyUI 队列并发位是否被占、是否需要给 TTS 任务加独立超时
      中断与队列清理。
- [ ] **测试项目第 1 集剧本为 fallback 产物**（8 镜全部「模型分镜失败，按原文逐句
      承载」，motion/visual_detail 为空）：用 P1-3 的新 schema + 新提供商重新生成
      后复查；若仍失败，查分段 LLM 调用的报错根因。
- [ ] **环境变量 MJSCXT_PROMPT_ENHANCE 经 bat 注入未生效之谜**：bat 已 `set` 但
      新进程仍调用了增强（已改用 config 默认值绕过）。待查计划任务动作是否指向
      别的 bat 副本（`schtasks /query /tn MJSCXT_Flask /v /fo LIST` 看 Task To Run）。
- [ ] **Git Bash 不可用**（0xC0000139）：本机 Git Bash 仍无法启动，影响 git 提交与
      py_compile；期间所有 shell 操作经 Computer Use 走 PowerShell 完成。
