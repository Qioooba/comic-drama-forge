# 改造契约（并行实施协调书）

> 本文件是 2026-10-07 对标 LocalDramaStudio 改造的**跨 agent 协作契约**。
> 目的：让 8 个并行 agent 在**文件所有权互斥**的前提下各自落地，互不覆盖。
> **任何 agent 都不得修改本文件，也不得修改未分配给自己的文件。**

---

## 0. 铁律（违反即回滚）

| # | 铁律 | 原因 |
|---|---|---|
| R1 | **URL 逐字不变** | `frontend/src/api/client.ts` 1508 行全靠字符串拼 URL；改一个字符前端就 404 |
| R2 | **不改任何既有报错文案** | `failure_codes.py` 从既有文案推导错误码；改文案=断契约 |
| R3 | **禁止调用 GPU / ComfyUI** | 用户 RTX 3090 Ti 正在跑自己的任务。所有验证只做静态检查与纯 CPU 导入 |
| R4 | **不写测试、不跑测试** | 本轮只做「实现 + 审核」，测试留到下一轮 |
| R5 | **新功能一律加新文件** | 既有大文件（`app.py` 16.8k 行 / `ProjectWorkbenchPage.tsx` 5.1k 行）本轮只做纯搬迁，不加新逻辑 |
| R6 | **中文注释、单引号风格随既有文件** | 后端 Python 用 `# -*- coding: utf-8 -*-` + 中文 docstring；前端 TS 用 `'单引号'` |

## 2. 共享运行时上下文（`app/api/_shared.py`）

W1 拆分时，242 条路由共用的**模块级状态**必须集中到 `app/api/_shared.py`。
其它 agent（W2/W3/W4/W7）**只读**该模块，不得修改。

```python
# app/api/_shared.py 暴露：
app                 # Flask 实例（composition root 注入）
comfyui_client      # ComfyUIClient 实例
script_gen          # ScriptGenerator 实例
video_processor     # VideoPostProcessor 实例
task_db, task_queue # 任务存储
generation_state, lock
config 常量全集（CHARACTERS_DIR / PROJECT_OUTPUT_DIR / QC_CONFIG_PATH ...）
```

新域蓝图（`app/api/production_facts.py` 等）按同一约定暴露模块级 `bp`，
由 `app/api/__init__.py` 的自动发现机制注册，**无需改 `app.py`**。

## 4. 「采用 ≠ 批准」不变量（后端与前端共同遵守）

这是本次改造的核心语义，**所有 agent 都必须遵守**：

> `SelectionDecision`（采用）**永不**隐式升级为 `ApprovalDecision`（批准）。
> 批准必须带人工授权 + 哈希绑定；UI 上 `selected` 永不显示为 `approved`。

- W2 定义数据模型与状态机。
- W3 交付包批准闸门必须校验「人工授权」而非「机器检查通过」。
- W5 Shot Studio 组件必须给「采用」「批准」两个**独立按钮**。
- W6 设计令牌必须新增 `--selected`（青）与 `--approved`（绿）两档，**不得**继续复用 `--state-done`。
