## 二、本地系统架构概览

### 核心文件

| 文件 | 大小 | 职责 |
|---|---|---|
| `novel_to_script.py` | 152KB / 2310+行 | 小说→A版剧本（三段式流水线） |
| `dialogue_utils.py` | 17KB | 台词结构化 + 说话人推断 |
| `h3_prompt_kit.py` | 62KB / 1187+行 | MiniMax H3 六段提示词构建 |
| `asset_prompt_kit.py` | 49KB | 角色/场景/道具参考图提示词 |
| `continuity.py` | 113KB | 跨集连续性管理 |
| `coverage.py` | 35KB | 原文覆盖率追踪 |
| `prompt_qc.py` | 73KB | 提示词质量检查 |
| `comfyui_client.py` | 180KB | ComfyUI 工作流对接 |

### 现有流水线

```
小说原文
  ↓ [分块：2400字/块]
  ├─ ① 逐块提炼（剧情摘要/人物/物品/场景/情节要点）
  ├─ ② 汇总设定（title/theme/style/characters[]/items[]/scenes[]）
  └─ ③ 逐块写分镜（shots[]，含 description/dialogue/camera/audio_cues）
       ↓
  A版剧本 Schema → 落盘 output/scripts
       ↓
  h3_prompt_kit 自动构建六段提示词（不允许 LLM 直接写 prompt_h3）
       ↓
  ComfyUI H3 Director 批量生成 → 后处理 → 成片
```

## 四、值得补充的 5 个缺口（按优先级）

### 缺口 1（P0）：道具"三问"严格过滤

**来源**：Huobao Drama extractor SKILL

**现状**：`script_generator.py` 提取道具"通常2-5个"，直接生成参考图。

**Huobao 做法**：
> 宁可少提不要多提。一集 0-3 个。三问：
> 1. 删掉它剧情还成立吗？→ 成立则不提
> 2. 只是随手用的日常物品吗？→ 是则不提
> 3. 只是场景陈设吗？→ 是则不提

**改动**：`novel_to_script.py` 提取prompt加三问，上限收紧到0-3个。
**收益**：减少无效参考图，降显存。

---

### 缺口 2（P1）：节拍识别 → 镜头切段边界

**来源**：Huobao Drama storyboard-breaker + ViMax叙事规划

**现状**：按字数密度均匀切镜，同一因果链可能被拆散。

**Huobao 做法**：
> 先识别【开场】【触发】【高潮】【收尾】节拍，节拍边界强制切段。
> 过渡段8-10s / 叙事段10-15s / 爆点段12-15s。

**改动**：`REWRITE_RULES` 加节拍识别，爆点镜时长加成。
**收益**：叙事节奏专业度提升。

---

### 缺口 3（P2）：negative prompt 自动生成

**来源**：penshot

**现状**：`h3_prompt_kit.py` 只构建正向提示词，没有 negative prompt。

**penshot 做法**：
> 每个fragment自动生成negative_prompt（cartoon, anime, 3D render, bright lighting, text, watermark...）

**改动**：`h3_prompt_kit.py` 加 negative prompt 段，按风格自动排除不想要的元素。
**收益**：减少H3出片的意外风格偏移。

---

### 缺口 4（P3）：角色/道具名称归一化去重

**来源**：Huobao Drama extractor

**现状**：去重靠LLM自觉，跨集可能重复生成参考图。

**Huobao 做法**：
> 先读已有角色列表，近名（带括号）自动归一化匹配，命中复用不重新生成。

**改动**：提取prompt注入已有资产列表，名称归一化后匹配。
**收益**：跨集一致性，省生成时间。

---

### 缺口 5（P4）：场景头显式分组

**来源**：Huobao Drama script-rewriter

**现状**：每镜有location字段，但无场景块分组。

**Huobao 做法**：
```
## S01 | 内景·咖啡厅 | 黄昏
```

**改动**：Schema加scene_blocks层，同场景共享lighting/atmosphere。
**收益**：同场景光线一致性。

## 五、本地系统已领先的能力

以下能力本地系统已经**超过所有8个开源项目**：

1. **跨集连续性**（state_in/out、时间锚点、转场检测、伏笔追踪）— 所有项目都没有
2. **原文覆盖率追踪**（0.70阈值，自动补生成）— 所有项目都没有
3. **按时长自动拆集**（180s上限，实测密度标定）— 其他项目手动
4. **H3六段提示词深度定制**（6000字符闸门）— 其他项目是通用格式
5. **台词四级回退推断**（前缀→包含→自称→出场首位）— 其他项目直接标注或无
6. **道具回环锚点**（≥2次出现标"视觉锚点·第N次"）— 其他项目只做ID绑定
7. **运镜克制策略**（75%固定镜头）— 适合AI视频
8. **ComfyUI本地部署对接**（180KB）— 其他项目走API
